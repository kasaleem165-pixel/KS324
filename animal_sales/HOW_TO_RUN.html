🌻 Animal Sales Records

Follow these 3 simple steps to run the program on your Windows laptop.

1

Install Python (one-time only)

Python is the engine that runs this program. You only install it once.

⭳ Download Python from python.org
IMPORTANT: During installation, tick the checkbox that says "Add Python to PATH" before clicking Install Now. If you miss this, the program won't start.
[ ] Install launcher for all users [✓] Add Python to PATH ← TICK THIS BOX [ Install Now ]
↓
2

Put the program folder on your laptop

Save the animal_sales folder anywhere on your laptop — for example on your Desktop or in Documents.

The folder should contain these files:

📁 animal_sales\
  📄 app.py
  📄 run.py
  ▶️ START.bat  ← this is your launcher
  📄 requirements.txt
  📁 templates\
↓
3

Double-click START.bat to launch

Open the animal_sales folder and double-click START.bat. A black command window will appear for a few seconds, then your browser will open automatically with the app.

✓ The browser opens at http://localhost:5000 — that is your app running.
✓ First launch installs Flask automatically (needs internet, takes ~10 seconds).
✓ After that, it starts instantly every time, even without internet.
Keep the black window open while using the app. Closing it stops the program. To stop the app intentionally, just close that window.

✓ That's it! Your app is running.

Open your browser and go to:

http://localhost:5000

Your data is saved in a file called sales.db inside the animal_sales folder.
Keep that file safe — it holds all your animal and sale records.
